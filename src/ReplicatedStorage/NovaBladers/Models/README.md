# Bey Studio Models

Import Creator Store or custom 3D models here for in-game use.

After Studio import: `ReplicatedStorage → NovaBladers → Models → [Name]`

| Studio folder name | Bey |
|--------------------|-----|
| `NovaStriker` | Nova Striker |
| `IronShell` | Iron Shell |
| `VoltDash` | Volt Dash |
| `ShadowBite` | Shadow Bite |
| `CrimsonRipper` | Crimson Ripper |
| `FrostMonarch` | Frost Monarch |

## Creator Store meshId (alternative)

Paste `rbxassetid://...` into `modelAssets.meshId` in `BeyCatalog.lua` for each bey.
Procedural layers are skipped when a mesh or studio model is present.

See `docs/BEY-MODELS.md` for full setup steps.
