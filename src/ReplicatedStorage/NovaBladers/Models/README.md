
Import Sketchfab GLB here as **NovaStriker** for in-game use.
See docs/SKETCHFAB-NOVA-STRIKER.md

- ReplicatedStorage → NovaBladers → Models → NovaStriker
- ReplicatedStorage → NovaBladers → Models → BlazeWheel (optional Creator Store mesh)
- ReplicatedStorage → NovaBladers → Models → FrostVeil (optional Creator Store mesh)

Or set `modelAssets.meshId` in BeyCatalog.lua after inserting a Toolbox model.
