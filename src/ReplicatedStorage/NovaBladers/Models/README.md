
Import Sketchfab GLB here as **NovaStriker** for in-game use.
See docs/SKETCHFAB-NOVA-STRIKER.md

After Studio import: ReplicatedStorage → NovaBladers → Models → NovaStriker

## Creator Store import slots

Optional 3D models from Roblox Creator Store (Toolbox → Creator Store → "spinning top"):

| Model name | Bey | Search hint |
|------------|-----|-------------|
| NovaStriker | Nova Striker | Sketchfab GLB or Creator Store |
| IronShell | Iron Shell | defense spinning top |
| VoltDash | Volt Dash | stamina / speed top |
| ShadowBite | Shadow Bite | balance / dark top |
| CrimsonBlaze | Crimson Blaze | red attack spinning top |
| FrostCrown | Frost Crown | ice crown / crystal top |

Procedural 3D fallbacks render automatically when no Studio model is present.
Alternatively, paste a MeshId into `BeyCatalog.modelAssets.meshId` for a single-mesh import.
