
Drop Creator Store or imported 3D models here as **Model** instances.
Name each model to match `modelRef.studioModelName` in `BeyCatalog.lua`:

| Model Name | Bey |
|------------|-----|
| `NovaStriker` | Nova Striker |
| `IronShell` | Iron Shell |
| `VoltDash` | Volt Dash |
| `ShadowBite` | Shadow Bite |
| `CrimsonFang` | Crimson Fang |
| `GlacierSpin` | Glacier Spin |

After Studio import: ReplicatedStorage → NovaBladers → Models → `<ModelName>`

If no model is present, procedural fallback layers are built automatically.
