# Bey Models (Creator Store / Studio Import)

Import spinning-top models from Roblox Creator Store or Sketchfab into Studio, then place them here:

`ReplicatedStorage → NovaBladers → Models → <ModelName>`

| Model Name   | Bey           | Fallback |
|--------------|---------------|----------|
| NovaStriker  | Nova Striker  | Procedural |
| IronShell    | Iron Shell    | Procedural |
| VoltDash     | Volt Dash     | Procedural |
| ShadowBite   | Shadow Bite   | Procedural |
| CrimsonFang  | Crimson Fang  | Procedural |
| FrostCrown   | Frost Crown   | Procedural |
| SolarCoil    | Solar Coil    | Procedural |

Optional: set `modelAssets.meshId` in `BeyCatalog.lua` for MeshPart IDs without a Studio model folder.

See also: `docs/SKETCHFAB-NOVA-STRIKER.md`
