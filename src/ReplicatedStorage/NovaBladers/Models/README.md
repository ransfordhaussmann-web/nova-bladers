# Imported Bey Models (optional)

Place Creator Store or custom imports here. Procedural meshes are used when no model is found.

| Model name | Bey | Import path |
|------------|-----|-------------|
| `NovaStriker` | Nova Striker | See docs/SKETCHFAB-NOVA-STRIKER.md |
| `CrimsonFang` | Crimson Fang | Studio → Models → CrimsonFang |
| `FrostCoil` | Frost Coil | Studio → Models → FrostCoil |
| `BlazeOrbit` | Blaze Orbit | Studio → Models → BlazeOrbit |

After Studio import: `ReplicatedStorage → NovaBladers → Models → <ModelName>`

Alternatively, set `modelAssets.meshId` in `BeyCatalog.lua` with a Creator Store rbxassetid.
