
Import Creator Store spinning-top models here for in-game use.

| Model name   | Bey          | Studio path                                      |
|--------------|--------------|--------------------------------------------------|
| NovaStriker  | Nova Striker | ReplicatedStorage → NovaBladers → Models         |
| IronShell    | Iron Shell   | Same folder                                      |
| VoltDash     | Volt Dash    | Same folder                                      |
| ShadowBite   | Shadow Bite  | Same folder                                      |
| FrostPrism   | Frost Prism  | Same folder                                      |
| EmberCore    | Ember Core   | Same folder                                      |

**Studio import:** Toolbox → Creator Store → search "spinning top", insert model, rename to match `studioModelName` in `BeyCatalog.modelRef`, parent under `Models/`.

Procedural fallback in `BeyModelBuilder` when no Studio model is present.

See also: `docs/SKETCHFAB-NOVA-STRIKER.md` for Nova Striker Sketchfab import.
