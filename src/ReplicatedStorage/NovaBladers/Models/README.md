# Bey Model Imports

Place Creator Store or imported 3D models here as **Model** instances.
Procedural fallbacks run when a model is missing.

| Model name | Bey | Creator Store search |
|------------|-----|----------------------|
| `NovaStriker` | Nova Striker | spinning top attack pegasus |
| `IronShell` | Iron Shell | spinning top defense metal |
| `VoltDash` | Volt Dash | spinning top stamina yellow |
| `ShadowBite` | Shadow Bite | spinning top dark balance |
| `CrimsonForge` | Crimson Forge | spinning top red attack forge |
| `FrostCrown` | Frost Crown | spinning top ice crystal defense |

## Studio setup

1. Toolbox → Creator Store → search the query from the table
2. Insert model into Workspace, scale to ~3–4 studs wide, lay flat
3. Move to `ReplicatedStorage → NovaBladers → Models → <ModelName>`
4. Optional: set `PrimaryPart` or name collision part `Hull`

See `docs/BEY-MODELS.md` for meshId and Sketchfab import details.
