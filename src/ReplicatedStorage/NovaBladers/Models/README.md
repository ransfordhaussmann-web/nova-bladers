
Optional Creator Store / imported 3D models for in-game use.

Place each model under `ReplicatedStorage → NovaBladers → Models` with the exact name below.
If a model is missing, the game falls back to procedural layers from `BeyModelBuilder.lua`.

| Model name | Bey |
|------------|-----|
| **NovaStriker** | Nova Striker (Sketchfab import — see docs/SKETCHFAB-NOVA-STRIKER.md) |
| **IronShell** | Iron Shell |
| **VoltDash** | Volt Dash |
| **ShadowBite** | Shadow Bite |
| **CrimsonEdge** | Crimson Edge |
| **FrostHalo** | Frost Halo |

After Studio import: scale to ~3.5 studs wide, flat on arena floor, set PrimaryPart or `Hull`.
