# Bey Models — Studio Import

Import Creator Store or custom 3D models here as **Model** instances.
Each bey's `modelRef.studioModelName` in `BeyCatalog.lua` maps to a child of this folder.

| Studio Model Name | Bey |
|-------------------|-----|
| NovaStriker | Nova Striker |
| IronShell | Iron Shell |
| VoltDash | Volt Dash |
| ShadowBite | Shadow Bite |
| CrimsonFang | Crimson Fang |
| FrostCrown | Frost Crown |
| SolarCoil | Solar Coil |

If no model is found, `BeyModelBuilder` falls back to procedural 3D layers.

See `docs/BEY-MODELS.md` for import instructions.
