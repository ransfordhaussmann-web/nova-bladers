# Bey Models (Studio Import)

Place Creator Store or custom 3D models here. `BeyModelBuilder` clones by `modelRef.studioModelName`.

| Model name | Bey | Notes |
|------------|-----|-------|
| `NovaStriker` | Nova Striker | Optional Sketchfab import — see `docs/SKETCHFAB-NOVA-STRIKER.md` |
| `IronShell` | Iron Shell | Toolbox / Creator Store spinning top |
| `VoltDash` | Volt Dash | Toolbox / Creator Store spinning top |
| `ShadowBite` | Shadow Bite | Toolbox / Creator Store spinning top |
| `CrimsonFang` | Crimson Fang | Toolbox / Creator Store spinning top |
| `NeonPulse` | Neon Pulse | Toolbox / Creator Store spinning top |

**Studio path:** `ReplicatedStorage → NovaBladers → Models → <ModelName>`

Without a model file, procedural layered meshes are used automatically.
