
Import Creator Store or custom 3D models here for in-game use.

| Model name | Bey | Creator Store search hint |
|------------|-----|---------------------------|
| `NovaStriker` | Nova Striker | See docs/SKETCHFAB-NOVA-STRIKER.md |
| `CrimsonFang` | Crimson Fang | spinning top attack / crimson |
| `FrostCrown` | Frost Crown | spinning top ice / defense |
| `NeonSpire` | Neon Spire | spinning top neon / balance |

After Studio import: ReplicatedStorage → NovaBladers → Models → `<ModelName>`

If no model is present, procedural 3D layers are built automatically at runtime.
