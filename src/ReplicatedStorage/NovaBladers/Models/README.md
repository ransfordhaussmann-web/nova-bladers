# Creator Store Bey Models

Optional 3D models from Roblox Creator Store. Procedural fallbacks work without imports.

## Slots

| Model name | Bey | Studio path |
|------------|-----|-------------|
| `NovaStriker` | Nova Striker | ReplicatedStorage → NovaBladers → Models |
| `CrimsonVortex` | Crimson Vortex | same |
| `GlacierShield` | Glacier Shield | same |

## Import (Studio)

1. Toolbox → Creator Store → search "spinning top" (original IP only)
2. Insert model into `ReplicatedStorage/NovaBladers/Models`
3. Rename to match `studioModelName` in `BeyCatalog.lua`
4. Or set `modelAssets.meshId` to an `rbxassetid://` in the catalog
