
Import Sketchfab GLB or Creator Store models here for in-game use.

## Studio import paths

| Bey | Folder |
|-----|--------|
| Nova Striker | `ReplicatedStorage/NovaBladers/Models/NovaStriker` |
| Blaze Vortex | `ReplicatedStorage/NovaBladers/Models/BlazeVortex` |
| Crystal Tide | `ReplicatedStorage/NovaBladers/Models/CrystalTide` |

See `docs/SKETCHFAB-NOVA-STRIKER.md` for Nova Striker GLB import.

## Creator Store (optional)

1. Studio → Toolbox → Creator Store → search `spinning top`
2. Insert model into `Models/<BeyId>` folder
3. Or set `modelAssets.meshId` in `BeyCatalog.lua`

Procedural 3D layers are used as fallback when no imported model is found.
