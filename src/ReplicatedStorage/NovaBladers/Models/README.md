## How to import

1. Roblox Studio → Toolbox → Creator Store → search `spinning top` / `bey blade`
2. Insert model into Workspace, scale to ~3–4 studs wide, lay flat
3. Move under `ReplicatedStorage → NovaBladers → Models → <studioModelName>`
4. Rojo sync or manual copy — procedural fallback runs if folder is missing

Nova Striker also has Sketchfab reference: see `docs/SKETCHFAB-NOVA-STRIKER.md`
