## Creator Store (optional)

Crimson Fang, Granite Fort, Solar Drift, and Phantom Edge support external meshes via
`modelAssets.meshId` in `BeyCatalog.lua`. Without a meshId they use procedural 3D models.

Studio Toolbox → Creator Store → search "spinning top" → paste rbxassetid into catalog.
