# Bey Models (Creator Store / Studio Import)

Importiere Creator-Store- oder eigene 3D-Modelle in Roblox Studio unter:

`ReplicatedStorage → NovaBladers → Models → <studioModelName>`

Wenn ein Model vorhanden ist, nutzt `BeyModelBuilder` es automatisch (Fallback: prozedurales Modell).

| studioModelName | Bey | Typ |
|-----------------|-----|-----|
| NovaStriker | Nova Striker | Attack |
| IronShell | Iron Shell | Defense |
| VoltDash | Volt Dash | Stamina |
| ShadowBite | Shadow Bite | Balance |
| CrimsonFang | Crimson Fang | Attack |
| GraniteFort | Granite Fort | Defense |
| SolarDrift | Solar Drift | Stamina |
| PhantomEdge | Phantom Edge | Balance |
| CrystalEdge | Crystal Edge | Attack |
| BlazeCrown | Blaze Crown | Balance |

## Nova Striker (Sketchfab)

Siehe `docs/SKETCHFAB-NOVA-STRIKER.md` für den GLB-Import als **NovaStriker**.

## Toolbox-Suche

Roblox Studio → Toolbox → Creator Store → „spinning top" / „beyblade" (nur als Referenz, eigenes IP verwenden)
