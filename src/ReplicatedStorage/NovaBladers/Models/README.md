# Bey Models — Studio Import Folder

Place imported Creator Store or FBX models here. `BeyModelBuilder` clones by `modelRef.studioModelName`.

| Folder name | Bey |
|-------------|-----|
| `NovaStriker` | Nova Striker (see docs/SKETCHFAB-NOVA-STRIKER.md) |
| `IronShell` | Iron Shell |
| `VoltDash` | Volt Dash |
| `ShadowBite` | Shadow Bite |
| `CrimsonFang` | Crimson Fang |
| `FrostRing` | Frost Ring |

**Creator Store shortcut:** Toolbox → Creator Store → search `spinning top` → insert → copy MeshId into `BeyCatalog.modelAssets.meshId` (procedural layers skipped when set).

**After Studio import:** `ReplicatedStorage` → `NovaBladers` → `Models` → `<studioModelName>`
