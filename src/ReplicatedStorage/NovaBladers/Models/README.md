# Creator Store Bey Models

Import Creator Store or custom 3D models into Studio under:

`ReplicatedStorage → NovaBladers → Models → <studioModelName>`

| Bey | studioModelName |
|-----|-----------------|
| Nova Striker | NovaStriker |
| Iron Shell | IronShell |
| Volt Dash | VoltDash |
| Shadow Bite | ShadowBite |
| Crimson Fang | CrimsonFang |
| Frost Crown | FrostCrown |
| Solar Coil | SolarCoil |

If no Studio model is found, procedural fallback models are used automatically.

Optional: set `modelAssets.meshId` in BeyCatalog for direct rbxassetid meshes.

See also: `docs/SKETCHFAB-NOVA-STRIKER.md` for Nova Striker Sketchfab import.
