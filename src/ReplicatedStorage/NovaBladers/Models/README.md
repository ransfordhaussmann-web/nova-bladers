## Creator Store meshes (optional)

Each bey in `BeyCatalog.lua` has a `modelAssets` slot. In Roblox Studio:
Toolbox → Creator Store → search "spinning top" → copy MeshId into `modelAssets.meshId`.
Procedural models are used when meshId is nil.
