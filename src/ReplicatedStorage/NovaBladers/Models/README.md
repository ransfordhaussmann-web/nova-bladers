# Creator Store Bey Models

Place imported Creator Store models here for in-game use.

| Slot | Bey | Creator Store search |
|------|-----|----------------------|
| `NovaStriker` | Nova Striker | (Sketchfab — see SKETCHFAB-NOVA-STRIKER.md) |
| `IronShell` | Iron Shell | `beyblade defense green shell` |
| `VoltDash` | Volt Dash | `spinning top yellow stamina` |
| `CrimsonFang` | Crimson Fang | `spinning top red attack` |
| `FrostCrown` | Frost Crown | `spinning top ice blue` |

After Studio import: `ReplicatedStorage → NovaBladers → Models → [ModelName]`

Alternatively set `meshId` in `CreatorStoreMeshes.lua` (MeshPart mesh from Toolbox).

Procedural fallback builds run when no model is present.
