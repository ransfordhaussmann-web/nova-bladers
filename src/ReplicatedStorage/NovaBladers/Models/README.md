After Studio import: ReplicatedStorage → NovaBladers → Models → NovaStriker

## Creator Store slots

| Folder name | Bey |
|-------------|-----|
| `CrimsonBlaze` | Crimson Blaze (Attack) |
| `FrostCrown` | Frost Crown (Defense) |

1. Toolbox → Creator Store → search `spinning top` / `bey blade`
2. Insert model, rename to folder name above
3. Move under `ReplicatedStorage/NovaBladers/Models/`
4. Optional: set `modelAssets.meshId` in `BeyCatalog.lua` instead
