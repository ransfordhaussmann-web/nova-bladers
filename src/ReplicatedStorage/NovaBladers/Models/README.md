
Import Creator Store / Sketchfab models here for in-game use.

## Studio Import

1. Toolbox → Creator Store → search "spinning top"
2. Import model into ReplicatedStorage → NovaBladers → Models
3. Rename to match `studioModelName` in BeyCatalog (e.g. CrimsonFang)

## Supported Models

| Bey | Folder Name | Search Terms |
|-----|-------------|--------------|
| Nova Striker | NovaStriker | Sketchfab GLB (see docs/SKETCHFAB-NOVA-STRIKER.md) |
| Crimson Fang | CrimsonFang | spinning top, attack |
| Granite Fort | GraniteFort | spinning top, defense |
| Solar Drift | SolarDrift | spinning top, stamina |
| Phantom Edge | PhantomEdge | spinning top, balance |
| Crystal Edge | CrystalEdge | spinning top, crystal |
| Blaze Crown | BlazeCrown | spinning top, fire |

Procedural fallback models are built automatically when no Studio model is found.
