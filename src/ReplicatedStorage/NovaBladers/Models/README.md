## Optional Creator Store meshes

New beys (CrimsonFang, GraniteFort, SolarDrift, PhantomEdge) ship with procedural models.
To use a Creator Store mesh instead, paste the rbxassetid into `BeyCatalog.modelAssets.meshId` for that bey.
