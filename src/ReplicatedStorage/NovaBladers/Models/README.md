## Creator Store (optional)

BeyCatalog entries may include `modelAssets.creatorStoreSearch` — search that term in
Roblox Studio Toolbox → Creator Store, then paste the `rbxassetid` into `modelAssets.meshId`.
Procedural models are used when no mesh is set.
