# Creator Store / Studio Models

Import spinning-top models from Roblox Studio Toolbox → Creator Store, then place them here.

| Model name   | Bey          | Notes                                      |
|--------------|--------------|--------------------------------------------|
| NovaStriker  | Nova Striker | Sketchfab GLB — see docs/SKETCHFAB-NOVA-STRIKER.md |
| IronShell    | Iron Shell   | Creator Store spinning top                 |
| CrimsonFang  | Crimson Fang | Creator Store attack-type top              |
| FrostCore    | Frost Core   | Creator Store ice/defense top              |

After import: `ReplicatedStorage → NovaBladers → Models → <ModelName>`

If no Studio model is present, `BeyModelBuilder` falls back to procedural geometry.
