# Bey Model Imports

Place Creator Store or imported 3D models here for in-game use.

| Model Name | Bey | Notes |
|------------|-----|-------|
| `NovaStriker` | Nova Striker | Sketchfab GLB import (see docs/SKETCHFAB-NOVA-STRIKER.md) |
| `CrimsonVortex` | Crimson Vortex | Creator Store spinning top — flat on ground |
| `GlacierMantle` | Glacier Mantle | Creator Store ice/defense top |

After Studio import: `ReplicatedStorage → NovaBladers → Models → <ModelName>`

Procedural layers are used as fallback when no model folder exists.
