# Bey Models (Creator Store / Studio Import)

Procedural fallbacks exist for all 7 Beys. Optional Studio imports go here:

| studioModelName | Bey |
|-----------------|-----|
| NovaStriker | Nova Striker |
| IronShell | Iron Shell |
| VoltDash | Volt Dash |
| ShadowBite | Shadow Bite |
| CrimsonFang | Crimson Fang |
| FrostCrown | Frost Crown |
| SolarCoil | Solar Coil |

## Import

1. Roblox Studio Toolbox → Creator Store → search "spinning top" / "bey"
2. Insert model under `ReplicatedStorage → NovaBladers → Models`
3. Rename to the `studioModelName` from the table above

Optional: set `modelAssets.meshId` in `BeyCatalog.lua` for direct MeshPart loading.

Nova Striker Sketchfab reference: see `docs/SKETCHFAB-NOVA-STRIKER.md`
