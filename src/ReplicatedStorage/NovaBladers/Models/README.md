
Import optional Creator Store spinning-top models here for in-game meshes.

| Model name | Bey | Notes |
|------------|-----|-------|
| `NovaStriker` | Nova Striker | Sketchfab GLB — see `docs/SKETCHFAB-NOVA-STRIKER.md` |
| `CrimsonFang` | Crimson Fang | Creator Store spinning top (~3.5 studs) |
| `FrostCore` | Frost Core | Creator Store spinning top (~3.6 studs) |

After Studio import: `ReplicatedStorage → NovaBladers → Models → <ModelName>`

Without imported models, procedural 3D layers are built at runtime.
