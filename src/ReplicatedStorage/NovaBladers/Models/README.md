# Creator Store Bey Models

Import Toolbox / Creator Store spinning-top meshes here for in-game visuals.

| Studio model name | Bey |
|-------------------|-----|
| CrimsonFang | Crimson Fang |
| GraniteFort | Granite Fort |
| SolarDrift | Solar Drift |
| PhantomEdge | Phantom Edge |

**Studio path:** `ReplicatedStorage → NovaBladers → Models → <ModelName>`

**Toolbox:** Search terms are in `BeyCatalog.modelAssets.creatorStoreSearch` per Bey.

Optional: set `modelAssets.meshId` in `BeyCatalog.lua` with an `rbxassetid://` mesh ID.
