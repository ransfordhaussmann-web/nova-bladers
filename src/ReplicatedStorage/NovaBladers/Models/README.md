## Creator Store (optional meshes)

For the 4 newer Beys, open Studio Toolbox → Creator Store and search using
`modelAssets.creatorStoreSearch` in `BeyCatalog.lua` (e.g. "spinning top red attack").
Paste the rbxassetid into `modelAssets.meshId` to replace procedural visuals.
