# Bey Models (optional Creator Store imports)

Procedural 3D models are built at runtime by `BeyModelBuilder.lua`.
Optional Creator Store meshes: set `modelAssets.meshId` in `BeyCatalog.lua`.

## Studio import (Sketchfab / Toolbox)

1. Toolbox → Creator Store → search "spinning top" (no official IP names)
2. Import mesh into `ReplicatedStorage → NovaBladers → Models`
3. Name folder after Bey id (e.g. `NovaStriker`, `CrimsonFang`)
4. Or paste `rbxassetid` into `BeyCatalog.modelAssets.meshId`
