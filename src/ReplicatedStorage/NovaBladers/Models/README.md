# Creator Store Model Imports

Place imported models here for in-game use. Each bey's `modelRef.studioModelName` in `BeyCatalog.lua` maps to a folder/model name below.

| Model Name | Bey | Creator Store Search |
|------------|-----|----------------------|
| NovaStriker | Nova Striker | spinning top blue attack |
| IronShell | Iron Shell | spinning top green defense |
| VoltDash | Volt Dash | spinning top yellow stamina |
| ShadowBite | Shadow Bite | spinning top purple balance |
| CrimsonForge | Crimson Forge | spinning top red metal forge |
| FrostCrown | Frost Crown | spinning top ice crystal crown |

After Studio import: `ReplicatedStorage → NovaBladers → Models → <ModelName>`

Procedural models are used when no Studio model is present.
