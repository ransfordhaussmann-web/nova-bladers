
Creator Store / Studio-Modelle für Nova Bladers.

## Import in Studio

Lege importierte Modelle unter `ReplicatedStorage → NovaBladers → Models` ab.
Der `studioModelName` in `BeyCatalog.lua` muss dem Modellnamen entsprechen.

| Bey | studioModelName |
|-----|-----------------|
| Nova Striker | NovaStriker |
| Iron Shell | IronShell |
| Volt Dash | VoltDash |
| Shadow Bite | ShadowBite |
| Crimson Fang | CrimsonFang |
| Frost Crown | FrostCrown |
| Solar Coil | SolarCoil |
| Blaze Quill | BlazeQuill |
| Tide Anchor | TideAnchor |

## Creator Store Mesh (optional)

Alternativ `modelAssets.meshId` in `BeyCatalog.lua` setzen (rbxassetid).
Ohne Import nutzt `BeyModelBuilder` prozedurale Fallback-Modelle.
