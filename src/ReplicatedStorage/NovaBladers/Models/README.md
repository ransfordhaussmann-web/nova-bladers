## Creator Store (andere Beys)

Für Iron Shell, Volt Dash, Shadow Bite, Crimson Blaze, Frost Crown:
Studio Toolbox → Creator Store → „spinning top“ → MeshId in `BeyCatalog.modelAssets.meshId` eintragen.
Ohne meshId wird das prozedurale Modell aus `BeyModelBuilder` verwendet.
