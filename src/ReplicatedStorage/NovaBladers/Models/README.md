
Import Sketchfab GLB here as **NovaStriker** for in-game use.
See docs/SKETCHFAB-NOVA-STRIKER.md

After Studio import: ReplicatedStorage → NovaBladers → Models → NovaStriker

## Creator Store (optional)

For the 4 newer Beys (Crimson Fang, Granite Fort, Solar Drift, Phantom Edge),
search Roblox Studio Toolbox → Creator Store using the `modelAssets.creatorStoreSearch`
string from `BeyCatalog.lua`. Paste the resulting `meshId` into `modelAssets.meshId`.
Procedural models are used as fallback when no mesh is set.
