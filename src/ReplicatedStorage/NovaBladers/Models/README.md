# Bey Model Import Slots

Place Creator Store or imported models here as **Model** instances. `BeyModelBuilder` clones them when present; otherwise procedural meshes are used.

| Studio model name | Bey |
|-------------------|-----|
| `NovaStriker` | Nova Striker |
| `IronShell` | Iron Shell |
| `VoltDash` | Volt Dash |
| `ShadowBite` | Shadow Bite |
| `CrimsonVortex` | Crimson Vortex |
| `GlacierMantle` | Glacier Mantle |

**Path in Studio:** `ReplicatedStorage → NovaBladers → Models → <studioModelName>`

See `docs/BEY-MODELS.md` for import steps and `docs/SKETCHFAB-NOVA-STRIKER.md` for Sketchfab workflow.
