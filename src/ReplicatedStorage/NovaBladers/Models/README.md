## Creator Store

Procedural 3D-Modelle sind eingebaut. Optional kann in `BeyCatalog.modelAssets.meshId` eine rbxassetid aus dem Roblox Creator Store gesetzt werden (`creatorStoreSearch` zeigt den Toolbox-Suchbegriff).
