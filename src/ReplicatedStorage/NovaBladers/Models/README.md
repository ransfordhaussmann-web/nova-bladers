## Creator Store (optional meshId)

New beys ship with procedural 3D models. To use Creator Store assets:

1. Studio Toolbox → Creator Store → search term from `BeyCatalog.modelAssets.creatorStoreSearch`
2. Insert model, copy `MeshId` / `TextureId`
3. Paste into `BeyCatalog.modelAssets.meshId` for that Bey
