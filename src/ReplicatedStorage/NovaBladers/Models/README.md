# Creator Store Bey Models

Import spinning-top models from Roblox Studio Toolbox → Creator Store into this folder.

| Model Name   | Bey          | Notes                          |
|--------------|--------------|--------------------------------|
| NovaStriker  | Nova Striker | Sketchfab ref in BeyCatalog    |
| IronShell    | Iron Shell   |                                |
| VoltDash     | Volt Dash    |                                |
| ShadowBite   | Shadow Bite  |                                |
| FrostPrism   | Frost Prism  |                                |
| EmberCore    | Ember Core   |                                |

After import: `ReplicatedStorage → NovaBladers → Models → <ModelName>`

If no Studio model is present, `BeyModelBuilder` falls back to procedural geometry.
