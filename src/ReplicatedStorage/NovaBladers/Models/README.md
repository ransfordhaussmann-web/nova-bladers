# Bey 3D Models (Creator Store / Studio Import)

Place imported Creator Store or custom models here. `BeyModelBuilder` auto-clones them when present.

| Model Name   | Bey          | Notes                                      |
|--------------|--------------|--------------------------------------------|
| NovaStriker  | Nova Striker | Sketchfab GLB — see docs/SKETCHFAB-NOVA-STRIKER.md |
| CrimsonFang  | Crimson Fang | Creator Store spinning top → Models folder |
| AuroraCrest  | Aurora Crest | Creator Store spinning top → Models folder |

**Studio path:** `ReplicatedStorage → NovaBladers → Models → <ModelName>`

**Alternative:** Set `modelAssets.meshId` in `BeyCatalog.lua` with an rbxassetid from Creator Store.

If no model is found, procedural fallback visuals are used automatically.
