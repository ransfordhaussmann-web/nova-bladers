# Creator Store Bey Models

Optional 3D models from Roblox Creator Store. Place imported models here as **Model** instances.

Path in Studio: `ReplicatedStorage → NovaBladers → Models → <studioModelName>`

| studioModelName | Bey | Notes |
|-----------------|-----|-------|
| NovaStriker | Nova Striker | Sketchfab GLB import (see docs/SKETCHFAB-NOVA-STRIKER.md) |
| IronShell | Iron Shell | Toolbox search: spinning top / defense |
| VoltDash | Volt Dash | Toolbox search: stamina ring |
| ShadowBite | Shadow Bite | Toolbox search: balance top |
| BlazeComet | Blaze Comet | Toolbox search: attack comet / fire top |
| FrostCrown | Frost Crown | Toolbox search: ice crown / defense top |

If no model is present, `BeyModelBuilder` falls back to procedural layered parts.
