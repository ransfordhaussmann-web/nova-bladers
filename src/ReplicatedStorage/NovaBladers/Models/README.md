
Import Creator Store or custom 3D models here for in-game use.

## Studio placement

`ReplicatedStorage → NovaBladers → Models → <studioModelName>`

| Model folder | Bey |
|--------------|-----|
| `NovaStriker` | Nova Striker |
| `IronShell` | Iron Shell |
| `VoltDash` | Volt Dash |
| `ShadowBite` | Shadow Bite |
| `BlazeComet` | Blaze Comet |
| `CrystalGuard` | Crystal Guard |

## How to import

1. Roblox Studio → Toolbox → Creator Store → search `spinning top` / `bey blade`
2. Insert model into Workspace, scale to ~3.5 studs wide, lay flat
3. Move under `Models/` with the matching folder name above
4. Optional: set `PrimaryPart` or name collision part `Hull`

If no Studio model exists, `BeyModelBuilder` builds a procedural fallback automatically.

See also: `docs/BEY-MODELS.md`, `docs/SKETCHFAB-NOVA-STRIKER.md`
