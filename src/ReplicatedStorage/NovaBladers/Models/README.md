# Bey Model Import Slots

Place Studio-imported Creator Store models here as **Model** instances:

| Folder name | Bey |
|-------------|-----|
| `NovaStriker` | Nova Striker |
| `CrimsonFang` | Crimson Fang |
| `FrostCrown` | Frost Crown |

After Studio import: `ReplicatedStorage → NovaBladers → Models → <BeyId>`

Alternatively set `modelAssets.meshId` in `BeyCatalog.lua` for a direct mesh asset.

See `docs/BEY-MODELS.md` and `docs/SKETCHFAB-NOVA-STRIKER.md` for setup details.
