
Creator Store / imported 3D models for in-game use.

Place models under `ReplicatedStorage/NovaBladers/Models/` in Studio:

| Model Name | Bey |
|------------|-----|
| NovaStriker | Nova Striker |
| IronShell | Iron Shell |
| VoltDash | Volt Dash |
| ShadowBite | Shadow Bite |
| BlazeComet | Blaze Comet |
| FrostCrown | Frost Crown |

If no Studio model is found, `BeyModelBuilder` falls back to procedural 3D layers.

See `docs/BEY-MODELS.md` for import instructions.
