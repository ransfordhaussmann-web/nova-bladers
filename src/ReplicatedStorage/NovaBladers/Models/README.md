## Creator Store (optional)

Procedural models work out of the box. To swap in Toolbox meshes:

1. Studio → Toolbox → Creator Store → search term from `BeyCatalog.modelAssets.creatorStoreSearch`
2. Import model into this folder as `CrimsonFang`, `GraniteFort`, `SolarDrift`, or `PhantomEdge`
3. Optional: set `modelAssets.meshId` in BeyCatalog for MeshPart fallback
