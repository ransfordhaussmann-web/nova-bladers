
Import Creator Store or custom 3D models here for in-game use.

## Supported model slots

| Model name | Bey | Import path |
|------------|-----|-------------|
| **NovaStriker** | Nova Striker | `ReplicatedStorage/NovaBladers/Models/NovaStriker` |
| **IronShell** | Iron Shell | `ReplicatedStorage/NovaBladers/Models/IronShell` |
| **CrimsonFang** | Crimson Fang | `ReplicatedStorage/NovaBladers/Models/CrimsonFang` |
| **FrostCore** | Frost Core | `ReplicatedStorage/NovaBladers/Models/FrostCore` |

See `docs/BEY-MODELS.md` and `docs/SKETCHFAB-NOVA-STRIKER.md` for import steps.

If no Studio model is present, procedural 3D layers are built automatically.
