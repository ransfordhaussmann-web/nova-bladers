
Import Sketchfab GLB or Creator Store models here for in-game use.

## Creator Store (Studio Toolbox)

1. Roblox Studio → Toolbox → Creator Store
2. Search: `spinning top`, `beyblade` (visual reference only — use original Nova Bladers names in-game)
3. Insert model, rename to match `BeyCatalog.modelAssets.studioModelName` (e.g. `CrimsonFang`)
4. Place under: `ReplicatedStorage → NovaBladers → Models`

Optional: paste `rbxassetid://…` into `BeyCatalog.modelAssets.meshId` for MeshPart fallback.
