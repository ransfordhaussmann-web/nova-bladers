
Import Creator Store or custom 3D models here as **Model** instances.
Folder name must match `modelRef.studioModelName` in BeyCatalog (e.g. CrimsonFang).

Supported Beys: NovaStriker, IronShell, VoltDash, ShadowBite, CrimsonFang, GraniteFort, SolarDrift, PhantomEdge, CrystalEdge, BlazeCrown

After Studio import: ReplicatedStorage → NovaBladers → Models → [BeyName]
