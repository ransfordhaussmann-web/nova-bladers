# Creator Store Bey Models

Import Creator Store / Toolbox models into Studio under:

`ReplicatedStorage → NovaBladers → Models`

| Model name | Bey | Notes |
|------------|-----|-------|
| NovaStriker | Nova Striker | Sketchfab GLB import (see docs/SKETCHFAB-NOVA-STRIKER.md) |
| IronShell | Iron Shell | Defense shell model |
| VoltDash | Volt Dash | Stamina ring model |
| ShadowBite | Shadow Bite | Balance fang model |
| CrimsonFang | Crimson Fang | Attack fang blades |
| FrostCrown | Frost Crown | Ice crown / crystal model |

If no Studio model is found, `BeyModelBuilder` falls back to procedural visuals or `modelAssets.meshId` in `BeyCatalog`.
