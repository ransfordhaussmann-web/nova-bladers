Import Creator Store / Sketchfab models here for in-game use.

| Model name   | Bey          | Studio path |
|--------------|--------------|-------------|
| NovaStriker  | Nova Striker | ReplicatedStorage → NovaBladers → Models → NovaStriker |
| BlazeOrbit   | Blaze Orbit  | ReplicatedStorage → NovaBladers → Models → BlazeOrbit |
| CrystalBloom | Crystal Bloom| ReplicatedStorage → NovaBladers → Models → CrystalBloom |

See docs/SKETCHFAB-NOVA-STRIKER.md for Nova Striker import.

Without a Studio model, procedural builders in BeyModelBuilder.lua are used automatically.
Alternatively set `modelAssets.meshId` in BeyCatalog for Toolbox mesh IDs.
