
Import optional 3D models here for in-game use.

| Folder name | Bey |
|-------------|-----|
| `NovaStriker` | Nova Striker (see docs/SKETCHFAB-NOVA-STRIKER.md) |
| `IronShell` | Iron Shell |
| `VoltDash` | Volt Dash |
| `ShadowBite` | Shadow Bite |
| `CrimsonEdge` | Crimson Edge |
| `FrostAnchor` | Frost Anchor |

After Studio import: `ReplicatedStorage → NovaBladers → Models → <Name>`

Alternatively, set `modelAssets.meshId` in `BeyCatalog.lua` with a Creator Store mesh ID.
