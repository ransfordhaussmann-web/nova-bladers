
Optional Creator Store models for in-game use.

| Model name | Bey | Studio path |
|------------|-----|-------------|
| NovaStriker | Nova Striker | ReplicatedStorage → NovaBladers → Models → NovaStriker |

| FrostVeil | Frost Veil | ReplicatedStorage → NovaBladers → Models → FrostVeil |
