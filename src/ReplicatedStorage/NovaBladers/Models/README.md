## Creator Store meshes (optional)

Crimson Blaze and Frost Crown support `modelAssets.meshId` in BeyCatalog.
Search Studio Toolbox → Creator Store → "spinning top", then paste the rbxassetid.
Without a meshId, procedural fallbacks are used automatically.
