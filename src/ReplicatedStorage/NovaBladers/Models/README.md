## Creator Store (optional)

New Beys ship with procedural models. To use Creator Store meshes instead:

1. Studio Toolbox → Creator Store → search the `creatorStoreSearch` term from `BeyCatalog.modelAssets`
2. Insert mesh, copy `rbxassetid://` MeshId into `BeyCatalog.modelAssets.meshId`
