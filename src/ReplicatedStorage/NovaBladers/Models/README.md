
Import optional Creator Store / Sketchfab models here for in-game use.

| Model name   | Bey          | Notes |
|--------------|--------------|-------|
| NovaStriker  | Nova Striker | See docs/SKETCHFAB-NOVA-STRIKER.md |
| BlazeWheel   | Blaze Wheel  | Creator Store → search "spinning top" / "fire top" |
| FrostVeil    | Frost Veil   | Creator Store → search "spinning top" / "ice top" |

After Studio import: ReplicatedStorage → NovaBladers → Models → `<ModelName>`

Optional: set `modelAssets.meshId` in BeyCatalog to use a Creator Store mesh without importing a full model.
