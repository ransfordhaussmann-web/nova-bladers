# Bey Models (Studio Import)

Place imported Creator Store / Sketchfab models here as **Model** instances.

| Studio model name | Bey |
|-------------------|-----|
| `NovaStriker` | Nova Striker |
| `IronShell` | Iron Shell |
| `VoltDash` | Volt Dash |
| `ShadowBite` | Shadow Bite |
| `CrimsonOrbit` | Crimson Orbit |
| `FrostAnchor` | Frost Anchor |

After import: `ReplicatedStorage → NovaBladers → Models → <ModelName>`

If no model is present, `BeyModelBuilder` builds a procedural fallback at runtime.

See `docs/BEY-MODELS.md` for Toolbox search and `modelAssets.meshId` option.
