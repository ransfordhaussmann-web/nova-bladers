
Import Creator Store / Sketchfab models here for in-game use.

## Studio import

1. Toolbox → Creator Store → search "spinning top" / "battle top"
2. Insert model into `ReplicatedStorage → NovaBladers → Models`
3. Rename to match `modelRef.studioModelName` in `BeyCatalog.lua`

| Bey | Studio model name |
|-----|-------------------|
| Nova Striker | NovaStriker |
| Iron Shell | IronShell |
| Volt Dash | VoltDash |
| Shadow Bite | ShadowBite |
| Crimson Blaze | CrimsonBlaze |
| Frost Crown | FrostCrown |

Procedural 3D fallbacks render automatically when no Studio model is present.

See docs/SKETCHFAB-NOVA-STRIKER.md for Nova Striker GLB import.
