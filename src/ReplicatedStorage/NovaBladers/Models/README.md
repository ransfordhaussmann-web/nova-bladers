# Bey Models (Studio Import)

Optional 3D meshes for in-game Beys. Procedural fallbacks work without any imports.

## Nova Striker

Import Sketchfab GLB as **NovaStriker**.
See `docs/SKETCHFAB-NOVA-STRIKER.md`

After Studio import: `ReplicatedStorage → NovaBladers → Models → NovaStriker`

## Blaze Wheel (Creator Store)

1. Roblox Studio → Toolbox → Creator Store → search "spinning top flame"
2. Insert mesh into `ReplicatedStorage → NovaBladers → Models → BlazeWheel`
3. Optional: paste `rbxassetid` into `BeyCatalog.modelAssets.meshId` for BlazeWheel

## Frost Veil (Creator Store)

1. Roblox Studio → Toolbox → Creator Store → search "spinning top ice"
2. Insert mesh into `ReplicatedStorage → NovaBladers → Models → FrostVeil`
3. Optional: paste `rbxassetid` into `BeyCatalog.modelAssets.meshId` for FrostVeil
