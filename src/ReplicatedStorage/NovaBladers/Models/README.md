
Import Creator Store or custom 3D models here for in-game use.

## Studio path

`ReplicatedStorage → NovaBladers → Models → <studioModelName>`

## Supported Beys

| studioModelName | Bey |
|-----------------|-----|
| NovaStriker | Nova Striker (see docs/SKETCHFAB-NOVA-STRIKER.md) |
| IronShell | Iron Shell |
| VoltDash | Volt Dash |
| ShadowBite | Shadow Bite |
| CrimsonBlaze | Crimson Blaze |
| FrostCrown | Frost Crown |

If no model is present, `BeyModelBuilder` falls back to procedural 3D layers.

After Studio import: set `PrimaryPart`, weld parts, optional `Hull` collision part.
