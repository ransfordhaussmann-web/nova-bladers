
Import Sketchfab GLB or Creator Store models here for in-game use.

| Model folder   | Bey            | Notes                          |
|----------------|----------------|--------------------------------|
| NovaStriker    | Nova Striker   | See docs/SKETCHFAB-NOVA-STRIKER.md |
| BlazeComet     | Blaze Comet    | Optional Creator Store mesh    |
| CrystalGuard   | Crystal Guard  | Optional Creator Store mesh    |

After Studio import: ReplicatedStorage → NovaBladers → Models → [ModelName]

Procedural fallbacks exist when no Studio model is present. Set `modelAssets.meshId` in BeyCatalog for Toolbox meshes.
