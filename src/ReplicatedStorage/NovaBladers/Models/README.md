## Creator Store models (optional)

| Model name   | Bey          |
|--------------|--------------|
| IronShell    | Iron Shell   |
| CrimsonFang  | Crimson Fang |
| FrostCore    | Frost Core   |

If no model is present, procedural visuals are used automatically.
