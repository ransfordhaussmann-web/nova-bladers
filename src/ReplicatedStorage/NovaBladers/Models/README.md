# Bey Models (Studio import)

Place imported Creator Store or custom 3D models here as **Model** instances.
Names must match `modelRef.studioModelName` in `BeyCatalog.lua`.

| Model name | Bey |
|------------|-----|
| NovaStriker | Nova Striker |
| IronShell | Iron Shell |
| VoltDash | Volt Dash |
| ShadowBite | Shadow Bite |
| CrimsonOrbit | Crimson Orbit |
| FrostAnchor | Frost Anchor |

**Nova Striker:** see `docs/SKETCHFAB-NOVA-STRIKER.md` for Sketchfab GLB import.

**Other beys:** Studio → Toolbox → Creator Store → search `spinning top` / `bey blade metal`,
insert into Workspace, scale to ~3.5 studs, move under this folder.

If no model is present, procedural layers from `BeyModelBuilder.lua` are used.
