
Import Sketchfab GLB or Creator Store models here for in-game use.

| Model name   | Bey           | Import path                                      |
|--------------|---------------|--------------------------------------------------|
| NovaStriker  | Nova Striker  | ReplicatedStorage → NovaBladers → Models           |
| BlazeWheel   | Blaze Wheel   | Toolbox → Creator Store → search "fire top"      |
| FrostVeil    | Frost Veil    | Toolbox → Creator Store → search "ice top"       |

After Studio import: ReplicatedStorage → NovaBladers → Models → `<studioModelName>`

Optional: paste `creatorStore.meshId` (rbxassetid) in BeyCatalog for direct mesh loading without Studio import.
See docs/SKETCHFAB-NOVA-STRIKER.md for Nova Striker Sketchfab import.
