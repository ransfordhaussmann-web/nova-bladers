## Creator Store (optional)

Each Bey in `BeyCatalog.lua` has `modelAssets.creatorStoreSearch` hints.
In Roblox Studio: Toolbox → Creator Store → search the hint → paste `meshId` into catalog.
Procedural models work without external assets.
