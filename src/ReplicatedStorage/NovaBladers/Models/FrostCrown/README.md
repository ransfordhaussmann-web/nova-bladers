Import a Creator Store spinning-top mesh as **FrostCrown** here.

1. Studio → Toolbox → Creator Store → search `spinning top` or `ice bey`
2. File → Import 3D (or insert from Toolbox)
3. Scale ~3.5 studs wide, flat on arena floor
4. Place under `ReplicatedStorage → NovaBladers → Models → FrostCrown`
5. Set PrimaryPart (or child named `Hull`)

Optional: set `modelAssets.meshId` in `BeyCatalog.lua` instead of cloning from this folder.
